STTR

Selective Test-Time Reasoning for Streaming Speech Translation

Simultaneous translation, one token at a time.

The English source arrives word-by-word. The system must emit Chinese before the sentence is over — and every committed character is frozen.

latency
0.0 s

Wait-k: a schedule, not a decision.

Read k source words, then write one target word per source word. Fixed. Content-blind.

source
target
k = 3 · target starts after the 3rd source word

The failure mode: early commitment.

The word bank arrives alone. Wait-k commits a guess. If the future reveals it was wrong, the guess is already unrecoverable.

visible at commit
"The bank was…"
银行 (financial)
Model picks the higher-prior reading and writes it. Frozen.
the true continuation arrives
"…teeming with frogs and dragonflies."
河岸 (riverbank)
Now obvious it was a riverbank. Too late — wait-k cannot retract.
What if the agent imagined several possible futures, and only committed when they all agree?

That is the core idea of STTR: selective test-time reasoning.

A three-step progression.

All three sample plausible futures. They differ in what they do with them.

01

DD / JS gate

when to wait

Measure disagreement (JS divergence) across futures. If too high — read more.

02

Future Literal LCP

what character is safe

Translate each future; commit the longest shared Chinese character prefix.

03

Token Consensus ★

what token is safe

Compare next-token distributions directly. Commit tokens all futures agree on.

How we measure "good translation".

Two complementary metrics — one counts matching words, one understands meaning.

BLEU

Overlap of n-grams
ref: he is in a family with six children
mt : he is in a family of six kids
→ partial match because kids ≠ children
✔ fast, deterministic, widely used
✘ strict: penalises synonyms & word-order

COMET

Neural meaning similarity
encoder: XLM-RoBERTa on (src, mt, ref)
regressor: trained on human DA scores
→ outputs ≈ "how likely a human ranks this well"
✔ tolerates synonyms & paraphrase
✔ correlates ≈ 0.75 with humans vs BLEU's ≈ 0.3
Token Consensus improves both: +6.01 BLEU on WMT19 AND +0.074 COMET — so the gain is real.

Measuring latency: Average Lagging (AL).

For each written target word yj, how many source words had been read? AL is the average gap against the ideal diagonal.

source
target
AL = avgj ( dj  −  (j−1)/γ )   ·   lower = less lag = more "live"

Where could this break? Honest limitations.

Being clear about where TC is weak — this is what the user asked about.

⚙️

Compute cost

K extra next-token calls per commit step. ≈ 1.5× wall-clock vs direct wait-k on a warm vLLM server.

🧊

Conservative intersection

One noisy future can empty the intersection and force a read. Soft quorum (≥80 % agree) is untested.

🔌

Needs top-P logprobs

Only works on translators that expose their next-token distribution. Black-box APIs (Claude, GPT stream) don't.

🌏

Language-pair coverage

Tested only EN→ZH. Chinese's lexical freedom is the exact failure mode TC fixes; languages without it may benefit less.

🎙️

Cascaded ASR ≠ streaming

Whisper is offline here. Full end-to-end streaming speech is still future work.

🎲

Stochastic futures

Sampling at T=0.7 means 2 runs can differ by ±0.2 BLEU. Fix the seed for reproducibility.

Yet it reliably improves. Why?

1

Consensus filters noise

Any single sampled future is wrong in some way; their intersection keeps only tokens every plausible future endorses — more robust than the point estimate wait-k uses.

2

Training-free & compounding

No gradient steps, no tuning. If the translator gets smarter tomorrow, TC inherits the improvement for free.

3

Uses the model's own confidence

Intersecting top-P logprobs is the model's own "what's plausible next" — not a heuristic over strings. That's why it tolerates synonyms Chinese characters that SemLCP can't.

Where it goes from here.

NEXT · 1

Soft quorum

Replace hard "all K agree" with "≥ 80 % of K agree". Preliminary ablations hint at recall gains.

NEXT · 2

Adaptive K

Use fewer futures on easy prefixes, more on ambiguous ones. Halves compute on average.

NEXT · 3

Streaming ASR

Replace offline Whisper with a streaming ASR so source and target are both truly online.

NEXT · 4

Other languages

EN→DE, EN→RU. Confirm the benefit isn't only from Chinese's lexical freedom.

Simultaneous MT is a safe-commitment problem, not a fixed-delay one.

  • Future-sampling gives the agent foresight without training.
  • Consensus at the token-ID level tolerates Chinese's lexical freedom.
  • Drops onto any translator that exposes top-P logprobs.
  • +3.67 BLEU / +0.037 COMET on CoVoST-1997, at essentially no extra latency.
